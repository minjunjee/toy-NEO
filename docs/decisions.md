# 정한 것

정한 것마다 날짜, 누가 정했는지, 무엇을, 왜, 그리고 어떤 것을 보면 다시 볼지를 적는다. 새로 정하면 아래에 이어 적는다.

| 날짜 | 누가 | 무엇을 | 왜 | 다시 볼 신호 |
|---|---|---|---|---|
| 2026-11-20 | 사용자 | 연구를 scaling과 evaluation의 두 축으로 다시 짠다. 새 부품을 얹지 않고 분석에서 나오는 당연한 질문을 던진다 | NEO에 부족한 곳이 많고, NEO의 theory가 좋은지 판단할 방법이 transfer 정확도 하나뿐이다 | 없음 |
| 2026-11-20 | 사용자 | evaluation을 메인 주제로 하고 scaling을 그 아래의 일로 둔다 | Claude Code가 낸 이유는 최종 정확도 하나로는 scaling에서 무엇이 왜 틀렸는지 가를 수 없다는 것이다 | 관찰에서 transfer 정확도만으로 실패가 다 설명될 때 |
| 2026-11-20 | 사용자 | 측정 도구를 먼저 만들지 않고, 더 어려운 상황에서 NEO를 학습시켜 무슨 문제가 생기는지 관찰하는 것부터 한다 | 어떤 측정이 필요한지는 NEO가 어떻게 틀리는지를 봐야 정해진다 | 없음 |
